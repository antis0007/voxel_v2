# Player UI

Follow [UI_RULES.md](UI_RULES.md) for every player-visible widget and string.
Default to the world, hotbar, vitals and crosshair. Show details on inspection,
hover, an open screen or a held key. Prefer state, slots, bars and measured values
to prose. Keep names consistent with item and machine definitions.

Description tiers follow UI_RULES.md IV.11a: default empty; Behavior up to 8 words;
Mechanic up to 14 words plus a data-derived cost. Standard items have no prose.
Shift reveals codex copy up to 50 words. Delete copy duplicated by visible stats.
