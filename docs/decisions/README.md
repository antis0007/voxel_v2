# Decision records

The bible requests `docs/decisions/`. New bible-protocol decisions live here;
earlier [ADRs 0001–0020](../adr/) remain at their existing paths. Use one global
number sequence. Do not copy or renumber historical decisions.

Every decision with more than a week's consequence needs context, options,
evidence, decision/status, consequences and reversal criteria. A pending spike
gets a proposed decision, never an invented result. Product decisions (title,
core reveal, changed permadeath rules) require the human under B.6.
