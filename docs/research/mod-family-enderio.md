# Ender IO

Scope: [Addendum A.3](../specs/MOD_ADDENDUM.md#a3-ender-io). Claims: [C-MC1/2/4](../specs/GAME_BIBLE.md#heavily-modded-minecraft-tech--magic--tinkers).

Primary evidence checked 2026-10-24: the [official site](https://www.enderio.com/) identifies compact conduits, machines, tools and armor and links the source and legacy wiki. It supports the family identity, but does not by itself establish every conduit filter, farming-station, travel-anchor or upgrade detail listed in A.3; these remain version-specific reference leads.

Mapping proposal: one cell may expose several network channels with typed ports; per-face rules decide insertion/extraction. Soul binding and machine tiers become recipe/modifier data. Anchors use A.15 LinkNetwork, and painter skins use building variants. The multi-channel graph is new network work; M4.

## What we adopt

Compact shared-space routing, legible face configuration, useful material tiers and machine specialization.

## What we reject

An Ender-specific second power/storage/teleport implementation; asserting unsupported filter or capacitor semantics from the landing page.

## What we improve

Show each routed channel and its failure state; flood, heat and charge hazards affect the same conduit materials as ordinary matter. Capacity, simulation cost and failure behavior require measured designs before implementation.
