## Preservation, authority and interpretation

- The exact former file is preserved as [MOD_FEATURE_MATRIX_LEGACY_20261024.md](MOD_FEATURE_MATRIX_LEGACY_20261024.md): **27,334 bytes**, SHA-256 **9c0fbd6af21523cb620ae831c3394ece1b2d15e8db518a34191971a074b667ad**. Original feature order becomes L001–L153. All 153 feature labels remain verbatim; original mappings, cost estimates, milestone counts and verification notes remain in that byte-identical artifact.
- Canonical owners and scheduling supersede historical mapping/milestone guesses. Every inherited numerical limit, recipe statistic, exact mechanic and version attribution is **unverified legacy provenance**, even when its label lacks an old unverified tag. Keeping a label does not adopt its exact number or make it a source fact. New adoption rows describe our intended mechanisms; R1 marks source/version details still needing the linked note or later source tracing.
- L034 retains the old AC-style wording only as a preserved label: the canonical target is an electric graph with material conductors. The author describes Forge Energy and hanging wires; an AC solver is unsupported. L057 retains its historical Step Crafter label, while the canonical source attribution recognizes base Refined Storage autocrafting. BYG and Oh The Biomes You'll Go are one alias family; We've Gone is a sequel, not the same version. Galacticraft 4/5 and their addons require explicit compatible version selection ([space note](mod-family-space.md)).
- **Depends on** lists existing master system IDs, never another mod-specific implementation. Rows are scheduled no earlier than the first capability of their listed owners; full integration still needs the SDD and its actual downstream dependencies. M3 starter M01/M05/M08/M15/M16 support the first-automation lesson; broad engineering remains M4. A first-automation slice does not imply all belts, voltage, multiblocks or machines ship in M3. Full three-route magic gates remain M6.
- **D*** = data only *after* all listed mechanisms and authoring/validation hooks exist. **S*** = a bounded adapter, query, controller configuration hook or UI extension after foundations; scope must be priced in the SDD. **N(shared)** = implement/extend the named canonical service once; later rows reuse it. None means the feature already exists. Old data-only estimates do not waive foundational code, conservation, migration or budget work.
- **L** = preserved unverified legacy label. Risk codes: R1 reference version/mechanic unverified; R2 determinism/order; R3 matter/energy accounting; R4 budget/memory/awake cap; R5 save/ownership migration; R6 clarity/onboarding/access; R7 physics/lore feasibility; R8 progression/balance/product choice. All cost/milestone values are proposals, not measured LOC or hardware results. H0–H5 targets are specified by the [hardware addendum](../specs/ADDENDUM_B_HARDWARE.md); class performance remains unmeasured here.
- Pillars: P1 Matter is real; P2 Systems over scripts; P3 Scale; P4 Two syntaxes, one physics; P5 Legible; P6 Agent-maintainable. Paths preserve all seven mission audiences **builder, engineer, mage, explorer, survivor, student, reader**, plus **hybrid**. A row can serve several without creating separate implementations. Every gameplay service must eventually expose grounded text queries/actions, even when reader is not its principal audience.

## Explicit remaining unknowns and next planning work

1. Pin reference versions before copying exact mechanics, quantities or recipes. Legacy stats remain unverified; source notes intentionally distinguish directly checked descriptions from untraced study checklists. In particular, TC4 nodes and TC6 aura, Galacticraft addon APIs, AE2 historical channel limits, Draconic reactor/Chaos behavior, Cave Dweller variants and several biome/structure catalogs remain source work.
2. The owner IDs and minimum scheduling are routing decisions. They do not supply B.3 struct sizes, deterministic algorithms, memory totals, migration plans or B.4 critic approval. Every N(shared) service and S* adapter still needs its own reviewed SDD; D* content waits for those hooks. Spike outcomes may revise schedules through ADRs.
3. S1–S10 remain unmeasured in this task. Resonance, pressure/liquids, integer orbit stability, civilization coherence, information pricing and shared field/time effects are open feasibility questions. Physics approximations and fictional exotic rules must be stated honestly in lore and education.
4. Cross-system ledgers must account for stored matter/energy, all external inputs, waste, decay and link transfers. A declared efficiency below one, a long recipe graph or a complete no-op matrix does not by itself prove conservation, meaningful chemistry or improved play.
5. C-MC1–5, C-N1–5, C-F1–3, C-Z1–4 and C-S1–7 remain unpassed obligations. The master plan assigns acceptance ownership. Blueprint identity, field matter sinks, local time modifiers, machine/region packing, permadeath, names and the core reveal require their designated design/product decisions; this matrix makes no silent product choice.
6. Documentation shape, 153-label retention, named-family coverage and owner references were inspected locally during generation. No game code, tests, scenarios, hosted CI, runtime capture or benchmark was added or run for this expansion.
