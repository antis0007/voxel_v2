## A.1 Obscuria Collection (Aquamirae, Pandorica, Lost Souls, Obscure Tooltips, Loot Journal, Fragmentum)
Study: atmospheric dungeon/biome design, boss encounters with phases and music, relic/puzzle treasures, stylized tooltips with animated stat display, pickup journal.
Adopt: themed deep-sea/ship-graveyard biome (ours: flooded trench biome with pressure, cold, darkness; wrecks as structures with cargo bodies), puzzle-gated relic rooms (pressure plates, fluid levels, light, temperature as puzzle inputs), boss phases driven by arena state, codex/loot journal, tooltip stat display showing *material-derived* stats and planes.
Mapping: biomes/structures = worldgen stages + RON templates; puzzles = rule content over planes; bosses = utility-AI sets + phase triggers; tooltips = UI schema reading item material properties.
Cost: data + small code (tooltip renderer). Milestone: M6 (world & depth), tooltips M3.

## A.2 Tinkers' Construct + PlusTiC + Tinkers' Complement, Construct's Armory, Silent Gear, Materialis
Study: part-based tools (head/binding/handle/large plates), material traits, modifiers/upgrades slots, smeltery multiblock (melting, alloying, casting into molds), tool leveling (TiC Tool Leveling), armor stations, material packs adding dozens of alloys and traits.
Adopt: every tool/weapon/armor piece is an assembly of parts, each part a material; traits are derived from the material table (conductive, flammable, magnetic, buoyant, lava-proof, self-repair for living materials, "jagged" for crystals); smeltery is a real multiblock with molten metal *liquid cells* at temperature; casting = pour into mold cell region; alloys = reaction rows on molten liquids; modifier slots; tool XP/leveling; sharpening/repair.
Better than: no hardcoded trait list — traits are rules keyed on material properties, so new alloys automatically get sensible traits; molten metal that spills burns and solidifies into real ingot/scrap bodies; tools interact with planes (a copper pick conducts lightning; a wooden handle burns).
Mapping: `assets/tools/parts.ron`, `traits.ron` (rules), smeltery = multiblock + reactions + confined liquid cells. Cost: new system (assembly + traits) + data. Milestone: M3.

## A.5 Space: Galacticraft, Ad Astra, Advanced Rocketry, Beyond Earth, Space BossTools, Extra Planets, Mars Base, Terrablender planets — BUT BETTER
Study: rocket tiers, launch pads, fuel refining, oxygen bubbles/sealers, space suits, moon/Mars/asteroids/Venus, space stations, satellites (solar, data), planetary resources, gravity differences, meteor showers, dungeons on moons, oxygen collector/compressor, cargo rockets, buggies/rovers.
Adopt and improve:
- Planets/moons/asteroids as worlds with physics constants (gravity, ambient pressure, temperature curve, atmosphere composition as gas mix, day length, radiation level, mana density, magnetic field), worldgen configs, and resource tables.
- **Oxygen as the real gas field**: no "oxygen bubble" block — sealers pressurize enclosed volumes (gas sim handles leaks, airlocks, explosive decompression); suits carry tanks; plants produce O₂ via growth rule; CO₂ scrubbers are machines running reactions.
- **Vacuum and pressure**: liquids boil off, unsealed habitats vent, bodies freeze/overheat by sun exposure (temperature plane with solar flux).
- **Rockets and ships are rigid bodies** with thrust (gas exhaust = real hot gas cells, launch pad burns), staging, fuel mass; "orbit" = a simplified 2-body model in a separate orbital layer (Kerbal-lite, integer orbital elements) with transfer windows; landing is physical.
- Space stations as player-built bodies in the orbital layer (modules, docking joints), satellites as entities providing services (solar relay → microwave receiver, mapping/scanning, comms for drones).
- Asteroid mining (bodies in the orbital layer brought down or mined in place), meteor events (bodies entering atmosphere, heat plane, craters).
- Life support chains: water recycling, food in hydroponics (growth needs light plane from lamps), radiation shielding (material density), power from RTG/solar/fusion.
- Rovers/buggies as vehicles; lunar dungeons; alien ruins (text-layer lore).
Mapping: worlds = worldgen config + physics constants; everything else is existing systems reused. Cost: new system (orbital layer, launch/landing flow), rest data + small code. Milestone: M6–M7.

## A.6 ICBM (Classic/Modern), DefenseTech, Modular Warfare-style explosives
Study: explosive tiers (conventional, incendiary, shrapnel, chemical, anvil, repulsive, attractive, EMP, nuclear, antimatter, red matter, sonic, breaching, thermobaric), missiles with launchers (tiers, range), radar, cruise launcher, EMP tower, detonators, grenades, minecart/missile cargo, remote detonation, camouflage/trap blocks.
Adopt: explosions are **pressure-pulse + heat + fragmentation** reaction events; each explosive type = parameters (pulse radius/strength, heat, fragment bodies count/material, gas product, EMP charge drain, special field effects like gravity well/repulse via force field over cells); missiles = guided rigid bodies with thrust and a controller (target coordinates, radar lock); launchers as multiblocks; radar as sensor entity feeding the signal network; EMP = charge plane drain + machine stun; nuclear = fission chain reaction (see A.8) producing fallout as a radioactive dust powder and radiation field; antimatter/red matter = extreme field effects (annihilation reaction rows, singularity body that attracts cells/bodies).
Better than: craters are physical (collapse, fluids rush in, fires spread); shrapnel is real bodies; fallout is real dust that settles and can be cleaned; EMP affects anything with charge.
Mapping: `assets/explosives.ron`, projectile/body controllers, sensor entities. Cost: small code (controllers, radar) + data; singularity body is a new body type. Milestone: M4 (basic), M7 (exotic).

## A.7 Force fields and security (Voltz era: MFFS / Modular Force Field System, Calclavia's Security & Electric Expansion; also Security Craft, OpenSecurity)
Study: force field projector with shapes (cube, sphere, tube, custom), modules (shock, sponge/liquid, disintegration, camouflage, silence, warp, anti-friction/anti-personnel, block access), field frequency and biometric identifier, interdiction matrix (anti-mob/anti-player/confiscate items), coercion deriver (power from Forcicium), fortron capacitor; Security Craft's keypads, retinal scanners, laser tripwires, cameras, reinforced blocks, alarms, mine, IMS.
Adopt: **forcefield cells** as a material class generated by a projector entity: a field cell is solid for a configurable set (cells, bodies, mobs, players, projectiles by filter), can carry modifiers (damage on contact, absorb liquids/gases, disintegrate matter into energy, camouflage material skin, reflect projectiles, slow time locally via tick-divisor); cost scales with surface area and modules; frequency/identity cards for access; interdiction matrix as area rule emitter; coercion deriver = reaction from a "forcicium" crystal; reinforced blocks = material with `toughness` cap; keypads/readers/tripwires/cameras/alarms as signal-network entities; camera view = render-to-texture on screens.
Better than: fields obey physics (an absorb-liquid field holds back a real dam; a shock field electrifies water), can be breached by exceeding their energy with explosives/accelerator beams; security logs go to the text layer.
Mapping: field cells = material class written by projector `Action`s each tick on dirty; filters in RON; signal entities. Cost: new system (field cells + projector) + data. Milestone: M4–M5 (projector), M7 (modules).

## A.8 Particle accelerators, nuclear physics, reactors (Atomic Science, NuclearCraft, ReactorCraft/RotaryCraft, Big/Extreme Reactors, IC2 reactors, Mekanism fission/fusion, GregTech reactors, Nuclear Science, Advanced Generators)
Study: ring accelerators (electromagnets, speed, antimatter/strange matter output), centrifuges/enrichment, fuel cycles (uranium → enriched → fuel rods → waste → reprocessing/breeding), reactor layouts (IC2's grid puzzle; Big Reactors' multiblock with moderators/coolant; NuclearCraft's heat/cooling placement rules), fusion (plasma, tokamak, deuterium/tritium), radiation (areas, items, contamination, decay over time), meltdown mechanics (corium, explosions), thermal management, steam turbines, RTGs, fission products, waste storage, decay chains, particle collisions producing exotic materials.
Adopt:
- **Neutron field** (optional plane): fissile materials emit neutrons per reaction row; moderators slow (multiply reaction probability), absorbers (control rods) reduce; criticality emerges from geometry — reactor design is real.
- Heat via temperature plane; coolant as liquid cells with real flow; steam from boiling; turbines kinetic; meltdown when temperature exceeds material limits → corium (liquid, hot, radioactive) that melts through floors; explosion if steam pressure cap exceeded.
- **Radiation field** (plane): emitted by materials by decay rows, attenuated by density, damages mobs/players, contaminates items (status flag), decays over time; fallout dust; Geiger tool; lead/water shielding physical.
- Fuel cycle as recipes + reactions (centrifuge = machine applying separation reaction; breeding = neutron-gated reaction); waste decay chains in RON with half-lives in ticks.
- Fusion: plasma as an ultra-hot gas material confined by magnetic field cells (forcefield class) in a torus multiblock; sustains when temperature and density thresholds are met; breach = plasma escapes physically.
- Particle accelerator: ring multiblock of magnet cells; a "beam" entity gains speed per magnet lap at power cost; collision chamber rows produce exotic materials (antimatter, strange matter, exotic mana isotopes), with failure modes (beam escapes → heat line through walls).
- Education profile: real isotopes, half-lives, cross-sections simplified but named; lesson scenarios (criticality, shielding, decay).
Better than: no layout minigame — geometry and physics *are* the puzzle; accidents are emergent.
Mapping: two optional planes (neutron, radiation), reaction rows, multiblocks, beam entity. Cost: new system (planes + beam) + data. Milestone: M4 (fission, radiation), M7 (fusion, accelerator).

## A.15 Cross-cutting requirements derived from this list (add to Part III/IV)

1. **Optional planes to budget for:** neutron, radiation, charge, pressure, mana, aspect, scent, light_sky, light_block, moisture, fertility, pollution (can alias gas materials), ghost/plan. Plane allocation is per brick on demand; the header bitset grows to 16 bits.
2. **Field-emitter entities** (environmental controller, beacons, modules/beacons, interdiction, terraformer, dimension stabilizer) share one implementation: `FieldEmitter { shape, radius, plane_ops[], filter, cost }` evaluated budgeted per tick on dirty or on a divisor.
3. **Controller VM** (RFTools Control, ComputerCraft/OC, PneumaticCraft drones, Hexcasting, Factorio combinators, missile guidance, robots): one sandboxed deterministic bytecode VM with a per-tick instruction budget, I/O through the signal network and `Action`s, programs stored as data; node editor and text editor front ends.
4. **Body controllers** (rockets, missiles, quarry heads, trains, drones, rovers, airships, golems): one `BodyController` trait with RON-configured behaviours (thrust vector, rail follow, target seek, path follow).
5. **Linked transport nodes** (tesseracts, ender chests/tanks, teleporters, travel anchors, flux networks, P2P): one `LinkNetwork` keyed by frequency/owner with energy cost per transfer and range tiers.
6. **Genetics evaluator** (bees, trees, crops, mob breeding, mutant beasts): one allele/dominance/mutation system with condition hooks on planes.
7. **Augment/modifier evaluator** (Thermal augments, TiC modifiers, Apotheosis affixes, enchantments, suit modules, Factorio modules, Draconic upgrades): one `Modifier` system applied to machines, items, mobs, and fields — rule attachments with stacking rules.
8. **Pocket worlds** (Compact Machines, AE2 spatial, Dimensional Doors, RFTools dimensions, cardboard box): region serialization to a sub-world with its own physics constants; the same code path as dimensions and as "pack this machine".
9. **Danger as a feature:** every energy form (electric, kinetic, heat, pressure, mana, neutron, radiation, antimatter) has a failure reaction row — overvoltage, over-stress, overheat, overpressure, mana flux, criticality, containment breach, annihilation — so player error and sabotage produce physical consequences.
10. **Education profile hooks:** every system above must expose a "real names and units" table and at least one lesson scenario (electrical safety, reactor criticality, orbital transfer, chemistry of ore processing, genetics inheritance, pressure and vacuum).
